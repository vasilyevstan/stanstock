# Security policy

## Reporting

Do not open a public issue containing credentials, private financial data, or
an exploitable vulnerability. Use GitHub's private vulnerability reporting or
a private security advisory for this repository.

Include the affected revision, reproduction steps, expected impact, and
whether the issue exposes authentication, provider credentials, prediction
history, portfolio data, or stored source assets.

## Supported version

Only the current `main` branch is supported during initial development.

## Scope

StanStock is designed as a private, single-owner application. A public,
multi-tenant, or multi-replica deployment is outside the current security
model and requires an explicit architecture and security review.
